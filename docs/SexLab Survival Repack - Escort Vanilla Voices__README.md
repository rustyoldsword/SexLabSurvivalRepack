# SexLab Survival Repack - Escort Vanilla Voices 1.0.0

New voice files for the six Hopeless Escorts, made as clones of vanilla Skyrim voice types so they sound like the
people around them. Each escort now has its own voice type:

| Escort | Voice type |
|---|---|
| Drunk Militiaman | MaleDrunk |
| Town Beggar | MaleSlyCynical |
| Scribe's Apprentice | MaleYoungEager |
| Farmhand | MaleNord |
| Frightened Recruit | MaleCoward |
| Retired Watchman | MaleOldGrumpy |

Contents: 2,246 loose FUZ files — every voiced escort line in `SL Survival - Hopeless Escorts Dialogue.esp` (305) and
`SL Survival - Hopeless Escorts Generic Voice.esp` (1,941). Text is unchanged. No plugin.

Requires the matching `SL Survival - Hopeless Escorts.esp` (the three changed voice types are in that plugin).
Place this mod above "SexLab Survival Repack" and "SexLab Survival Repack - Voices External".
