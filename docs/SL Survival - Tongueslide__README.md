# SL Survival - Tongueslide 1.0.0

Refitted SL Survival ahegao tongues (meshes\0halofarm\tongues\Female5\1-16). SLS ships the HALO tongue meshes
shifted ~1.3 up and ~1 back, so on UBE heads the tongue sat too high. These are rebuilt in BodySlide from the
HALOS Human HDT Tongueslide shape data (SLS 1-10 = HALO linga1-10, 11-16 = linga10).

Self-contained: the tongue textures (textures\tongue), the HDT physics file (meshes\morten\lingas\tong.xml), the .tri
files and the BodySlide projects + shape data are all inside, so HALOS Human HDT Tongues / Tongueslide are not needed.

Rebuild: BodySlide -> group "SL Survival Tongues" -> Batch Build (Tongue Up/Down/Forword/Back to fit).

Credits: HALO (tongues), ZMD78 (SSE conversion), ThrowawaySkyrimNesus (HDT), Shirou (HALOS Human HDT Tongues),
AtomiSkull (HALOS Human HDT Tongueslide).
